# In-session feedback survey

Clickable prototype of aiRA's in-session feedback prompt ("Was aiRA helpful in this session?").

Live page: https://annfrancis-rgb.github.io/In-Session-Feedback-Survey/

- The prompt appears about 2 seconds after the page loads, above the composer.
- Close the config panel (×) to see the wide layout; reopen it from the file card.
- **Restart** (bottom right) resets the session.
